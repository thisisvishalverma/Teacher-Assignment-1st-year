# Assignment 9: Debugging Notes

The corrected hobby page is written from scratch. It demonstrates the kinds of errors to check when debugging: document setup, matching heading and paragraph tags, correct nesting, descriptive image text, quoted links with a protocol, closed lists, table headings, and balanced closing tags.

## What to inspect in the corrected page

- The document starts with a doctype and sets its language.
- Every opening element has the correct closing element.
- Emphasis tags close in the reverse order in which they open.
- The image has useful alternative text and the link has a complete URL.
- The list and table have clear structure and headings.
