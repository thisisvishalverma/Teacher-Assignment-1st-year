# Assignment 19: Metadata Audit

I checked the HTML pages created for earlier tasks. The checklist below records what to verify in each page; it is not evidence that another person's computer or files were audited.

## Audit checklist

- [ ] Every page declares `<!doctype html>` and a document language.
- [ ] Every `<head>` contains a UTF-8 charset declaration.
- [ ] Every `<head>` contains a responsive viewport declaration.
- [ ] Every page has a unique, descriptive `<title>`.
- [ ] Every page has a short description that matches its content.
- [ ] Each referenced stylesheet and local image path exists.

The pages in this project use a title, character encoding, viewport, and description in the document head. Re-run this audit after editing or adding an HTML page.
