# HTML & CSS 45 Assignments

This project contains original, beginner-friendly work for the 45 HTML and CSS practical assignments. The attached assignment sheet and the [teacher's repository](https://github.com/singhanki189-max/Assignment) were used to understand the requirements; the teacher's code and writing were not used as submission content.

## Start here

- [Task-by-task plan](ASSIGNMENT_PLAN.md)
- [45-task checklist](CHECKLIST.md)
- `assignments/` contains the work grouped into the nine course modules.
- `assets/images/` contains original SVG illustrations used by the image exercises.

Each exercise has a numbered file name. Open a `.html` file in a browser to view it. The two multi-page projects are tasks 20 and 25; keep their files together so their shared `style.css` loads. If you use Live Server, open the project folder in VS Code and start it on the page you want to view.

## Personal pages

The resume, introduction, college, and portfolio pages use the personal details you supplied. The Open Desk club and product pages are fictional assignment examples; Bareilly is used as the sample club location.
